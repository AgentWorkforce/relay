# Agent Relay plugin for Capy (moved)

The Capy plugin now lives in the public skills repository so any Capy
organization can install it:

- Plugin: [`AgentWorkforce/skills`, path `plugins/capy/agent-relay`](https://github.com/AgentWorkforce/skills/tree/main/plugins/capy/agent-relay)
- Guided setup from any agent: [`setting-up-capy-on-agent-relay`](https://github.com/AgentWorkforce/skills/tree/main/skills/setting-up-capy-on-agent-relay)

In Capy, add the plugin from GitHub with that repository and path (or tell any
Capy thread "Install the Agent Relay plugin from GitHub AgentWorkforce/skills,
path plugins/capy/agent-relay"), sign in to Agent Relay, then say "Set me up on
Agent Relay" in a thread. If your organization installed it from this
repository's `integrations/capy`, remove that copy on Capy's MCP & plugins page
and add the public one.
